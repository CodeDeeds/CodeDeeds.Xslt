# CodeDeeds.Xslt
CodeDeeds.Xslt is a light weight XSLT transformation library written in .NET, with no dependencies to other than standard .NET system libraries. Does not implement 100% of the XSLT standard, but most of it.

Make sure to check if it matter for your use. See [XSLT Compatibility](XsltCompatibility.md) for details on supported features.

Most of the code is written with the help of Claude Code.
